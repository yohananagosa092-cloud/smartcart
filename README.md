# SmartCart

אפליקציית אנדרואיד לניהול רשימות קניות משותפות ולהשוואת עלות הסל בין חמש רשתות מזון: רמי לוי, שופרסל, יוחננוף, חצי חינם ואושר עד.

פרויקט גמר במדעי המחשב, התמחות Full Stack Development.

## צוות

- יסכה נגוסה: תשתית האפליקציה ובדיקות
- אורנאל דהן: ממשק המשתמש
- הודיה אזולאי: צד השרת

## מבנה המאגר

| תיקייה | תוכן |
|---|---|
| `app/` | אפליקציית האנדרואיד (Kotlin) |
| `functions/` | פונקציות הענן (TypeScript) |
| `docs/` | תיעוד: מודל הנתונים, מפרט ה-API וקובצי המחירים |

## איך עובדים

הענף `main` מוגן, ואי אפשר לדחוף אליו ישירות.

1. פותחים ענף למשימה, לדוגמה `feature/login-screen` או `fix/list-sync`.
2. כותבים קוד ודוחפים את הענף.
3. פותחים Pull Request.
4. חברת צוות נוספת סוקרת ומאשרת.
5. ממזגים ל-`main`.

## אבטחה

המאגר ציבורי. אין להעלות אליו סיסמאות, מפתחות או קובצי הגדרות של Firebase.
